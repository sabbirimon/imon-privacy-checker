Install the WordPress plugin

Drop the plugin into /wp-content/plugins/ and add [privacy_checker] to any page. Six-stage scan with real IP intel, MaxMind geo, reputation, traceroute, WebRTC, and an admin dashboard with logs.

1 Download

Grab the latest release from GitHub:

$ git clone https://github.com/sabbirimon/imon-privacy-checker.git

2 Upload

Zip the plugin/ folder and upload via wp-admin → Plugins → Add New.

$ cd plugin && zip -r ../imon.zip .

3 Activate

Activate, then add the shortcode to any page:

[privacy_checker]

Or try the v2 (beta) UI:

[privacy_checker_v2]
